AUTH SYSTEM
-----------
NO OTP. Password-based login only.

  Master user (the app owner):
  - Has a special master account
  - Adds new users manually — enters their mobile number + name
  - System auto-generates a random password for each new user
  - Master copies the generated password and sends it to the user manually
  - Master can remove users at any time

  Regular users:
  - Log in with mobile number + password
  - Must change password on first login
  - Can change password any time after that

  Password storage:
  - Never store plain text passwords — store bcrypt hash in Supabase
  - Session token returned on login, stored in SecureStore on device
